# Profile Card

A clean, responsive, and modern profile card built with HTML5 and CSS3.

## 🚀 Live Demo / Preview
To view the project locally:
1. Clone this repository or download the source code.
2. Open `index.html` in any modern web browser.

Alternatively, enable **GitHub Pages** in the repository settings (`Settings` > `Pages` > `Deploy from a branch: main / root`) to view it live on the web.

## ✨ Features
- **Modern UI & Aesthetic**: Sleek dark theme featuring subtle gradients, border glows, and clean typography.
- **Fully Responsive**: Optimized for both mobile devices and desktop viewports.
- **Semantic HTML5**: Structured using accessible elements (`main`, `article`, `aria-label`).
- **Interactive Elements**: Hover and focus transitions on call-to-action buttons.

## 🛠️ Built With
- **HTML5**
- **CSS3** (Flexbox & CSS Grid)
- **Google Fonts** ([Manrope](https://fonts.google.com/specimen/Manrope))
